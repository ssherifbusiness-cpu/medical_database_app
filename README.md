## How do I branch?

To create a branch for a backlog item (issue) from the Github Project board, you can navigate to the issue on the [Project Board](https://github.com/users/ssherifbusiness-cpu/projects/1)

From the issue's preview window you should be able to directly create a branch for it, and it should provide you with the commands to paste into your terminal to switch your target branch.

Alternatively, if the branch already exists, run *git fetch* and then *git switch branch_name* to target a new branch.
